# Imagens da página de vendas — Curso Restauração de Faróis

Suba aqui as imagens da página de vendas. A página será montada em
`restauracao-de-farois/index.html` e vai referenciar os arquivos desta pasta.

## Como nomear

Use nomes em minúsculas, sem espaços nem acentos, separados por hífen. Sugestão:

| Arquivo | Uso |
|---|---|
| `hero.jpg` ou `hero.webp` | imagem principal do topo |
| `logo-curso.png` | logo do curso (fundo transparente) |
| `antes-01.jpg`, `depois-01.jpg` | pares de antes e depois |
| `modulo-01.jpg`, `modulo-02.jpg`… | capa de cada módulo |
| `bonus-01.jpg`… | capa de cada bônus |
| `tarcisio.jpg` | foto do instrutor |
| `depoimento-01.jpg`… | prints de depoimentos |
| `garantia.png` | selo de garantia |

## Formato e tamanho

- Fotos: JPG ou WebP, largura máxima de 1600px, até 400 KB cada.
- Logos e selos: PNG com fundo transparente.
- Prints de depoimento: PNG ou JPG, largura de 800px.

Depois de subir, me avise que eu monto a página com elas.
